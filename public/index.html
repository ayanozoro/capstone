📖 Manual Setup Guide (If you prefer to configure GitHub manually)

Follow these steps if you want to configure your repository webhook by hand in GitHub Settings:

1

Open your GitHub Repository Settings

Go to your GitHub repo → Settings → Webhooks → Click "Add webhook".

2

Set the Payload URL (Smee.io Delivery URL)

Paste your Smee.io channel URL in the Payload URL field:

https://smee.io/4Dskqsw7XjXJssg7
3

Set Content type & Secret

Select Content type: application/json

Set Secret to match your .env file:

dghdfhsdfjsfgjsfgjf
4

Select Trigger Events

Choose "Just the push event" or "Let me select individual events" (check Pushes and Pull requests).

5

Save & Test!

Click "Add webhook". GitHub will send a test ping event immediately, which will appear in your Webhook Logs tab with a green status!
